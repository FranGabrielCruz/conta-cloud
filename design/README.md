# Referencias visuales de ContaCloud

Esta carpeta centraliza las referencias visuales del producto. La implementacion usa un lenguaje SaaS limpio: azul como accion primaria, verde para guardar, gris para cancelar, tablas paginadas a 10 registros, fechas `DD/MM/YYYY` y acciones compactas con iconos y tooltips.

Antes de agregar una pantalla, incorporar aqui su referencia aprobada y comprobar que el resultado sea responsive y consistente con el layout principal.
